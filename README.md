Aplikasi Pencatat Keuangan
Pencatat Keuangan adalah sistem atau aplikasi yang digunakan untuk mencatat, melacak, dan mengelola setiap arus uang masuk (pemasukan) dan uang keluar (pengeluaran) secara sistematis.
Tujuannya adalah untuk memudahkan seseorang memantau kondisi keuangan harian, mengetahui ke mana saja uang dihabiskan, serta menghitung sisa saldo secara akurat agar pengeluaran tetap terkontrol.

1. index.html (Kerangka / Tulang Punggung)
Fungsi: Membuat struktur halaman web.
Isi:
Kotak informasi saldo, kolom formulir input data (keterangan, jumlah uang, jenis pemasukan/pengeluaran), serta tabel daftar riwayat transaksi.

3. style.css (Desain / Pakaian)
Fungsi: Mempercantik dan merapikan tampilan web agar enak dilihat.
Isi:
Mengatur warna (hijau untuk pemasukan, merah untuk pengeluaran), tata letak kotak, kerapian tombol, dan bentuk tabel agar terlihat modern.

5. script.js (Logika / Otak)
Fungsi: Membuat web bisa berfungsi secara interaktif.
Isi:
Menghitung total uang masuk, uang keluar, dan sisa saldo secara otomatis.
Menambahkan riwayat transaksi baru ke tabel secara real-time.
Menyimpan data agar tidak hilang meskipun halaman browser ditutup (Local Storage).
